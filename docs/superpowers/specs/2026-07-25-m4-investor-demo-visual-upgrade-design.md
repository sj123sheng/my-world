# M4 投资人演示版视觉升级设计

**日期**：2026-07-25  
**阶段**：M4 Task 3–6 重新设计  
**状态**：对话设计已确认，待书面审核  
**目标设备**：Pura 70 Pro 模拟器用于视觉与功能验证；真实性能结论必须来自真机

## 1. 背景与问题

Task 1、Task 2 已完成输入动画、环境加载和性能降级等工程能力，但设备截图仍呈现为
工程验证场景：大面积灰色地面缺少前中远景，出生点没有视觉焦点，角色和敌人仍带有
高饱和基础几何体观感，写实遗迹与角色风格割裂，HUD 是常驻调试面板，Boss 也缺少
可识别轮廓、登场仪式和战斗节奏。

继续增加几何体或微调参数不能解决系统性的视觉不一致。后续任务必须从“功能逐项可用”
转为“5–7 分钟内稳定形成三个可复述画面”，并重新约束资产、构图、流程和验收方式。

## 2. 已确认决策

- 美术方向采用“风格化暗黑遗迹”，保留现有遗迹资产，但统一重做构图、材质、灯光、
  角色、Boss、VFX 和 HUD 的视觉语言。
- 取消 M4 零美术预算限制，允许购买少量商用素材，总预算不超过 500 元。
- 主要采购预算只投入 Boss；玩家、普通敌人、HUD 和 VFX 使用合规免费资产及程序化效果。
- Boss 原型采用“共鸣核心祭司”：类人本体配合悬浮环、碎片和三色能量核心。
- 演示采用引导式体验：保留移动与战斗操作，通过路径、触发器和短镜头控制节奏。
- HUD 采用电影化中心轴布局，调试数据默认隐藏，通过独立开关显示。

## 3. 演示流程

完整演示控制在 5–7 分钟。

### 3.1 冷启动钩子（0:00–0:20）

黑场出现三色共鸣脉冲，镜头穿过遗迹拱门，短暂显露共鸣核心祭司的悬浮轮廓，随后
无缝回到玩家控制。首屏直接呈现前景遮挡、中景玩家、远景祭坛和核心光源，不从空旷
灰地开始。

### 3.2 环境探索（0:20–1:30）

玩家沿受控但非硬走廊的路线进入遗迹。光带、雾门和地标负责引导；动态雾、悬浮碎片、
植被或遗迹能量流用于展示世界表现力。

### 3.3 基础战斗（1:30–2:40）

一组小型敌人在 30–45 秒内解决，展示移动、攻击反馈、命中特效和运行稳定性。战斗结束
后自动吸收第一种共鸣能量，不以敌人数量制造压力。

### 3.4 三源共鸣教学（2:40–3:40）

通过三个短交互依次激活三种能量，不弹出大段说明。每次激活同步改变角色轮廓光、
环境色和技能反馈，HUD 只显示当前目标与三个共鸣槽。

### 3.5 Boss 登场（3:40–4:15）

进入核心祭坛后接管镜头 6–8 秒：环体启动、碎片升空、三色能量聚合，Boss 从核心显形。
镜头随后平滑恢复到可操作视角。

### 3.6 Boss 战与收尾（4:15–6:40）

Boss 仅设两个阶段。第一阶段展示可读攻击与闪避；半血后打碎外环并切换三色能量，
玩家使用三源共鸣完成反制。最终一击触发短慢动作和环体坍缩，结尾只保留产品标题、
三源共鸣标志和一句定位语。

## 4. 统一视觉系统

### 4.1 场景与构图

- 重排出生点、主路线、战斗区和祭坛，移除大片无内容灰地。
- 前景使用残墙与碎石遮挡，中景承载玩家和交互，远景以高塔、拱门和 Boss 核心聚焦。
- 现有环形遗迹资产可以复用，但演示主路线必须明确；开放绕行不再优先于镜头质量。

### 4.2 色彩、灯光与雾

- 环境限定为低饱和蓝灰和石墨黑。
- 三源能量固定为青绿、紫红和琥珀三色；不再使用高饱和占位色或整片红色 Boss 地面。
- 主方向光塑造遗迹轮廓，祭坛提供冷色体积光，弱能量光负责路径引导。
- 距离雾分离前、中、远景；Boss 登场时降低环境亮度，提高核心和轮廓对比。

### 4.3 角色、敌人与 Boss

- 玩家替换为合规免费人形角色，使用深色材质、青绿轮廓光和统一武器特效消除拼接感。
- 普通敌人允许复用模型，但必须使用统一暗色材质和单色核心，不保留基础几何占位物。
- Boss 采购类人骨骼模型；悬浮环、三块碎片、三色核心和破环效果由程序化渲染实现。

### 4.4 VFX 与品牌图形

共鸣 VFX 只建设一套可复用语言：环形波纹、粒子拖尾、地面符文、命中闪光和轮廓脉冲。
三种能量共享形状，仅改变颜色、速度和扰动。标题、HUD、祭坛和 Boss 核心共同使用
“同心环 + 三分节点”图形，形成统一品牌符号。

### 4.5 HUD

- 当前目标短暂显示在顶部中心。
- 角色下方显示细生命条、能量条和三个共鸣槽。
- 屏幕角落只保留必要操作提示，首次使用后淡出。
- FPS、Draw Calls、骨骼数等数据放入可切换技术面板，不得常驻遮挡产品画面。

## 5. 技术架构

### 5.1 演示编排

新增独立 `DemoDirector` 状态机，管理开场、探索、遭遇战、三源激活、Boss 登场、Boss
两阶段和收尾。状态机只编排现有角色、战斗、相机、场景和 UI 系统，不将流程判断散落
在渲染循环中。

每个阶段同时支持空间触发、完成条件和超时兜底。玩家走错方向时重新显示光带；战斗
超过目标时长时可降低敌人生命或开放终结交互。提供默认隐藏的阶段快捷入口，现场异常时
可跳至探索、Boss 登场或 Boss 战。

### 5.2 镜头与输入恢复

增加可打断的短镜头轨道。过场暂时接管相机和输入，正常结束、手动跳过或异常中断都必须
恢复输入、相机目标和 HUD。恢复逻辑需要独立测试，避免卡在不可操作状态。

### 5.3 渲染能力边界

在现有 GLES3 管线上优先实现距离雾、颜色分级、轮廓光、发光材质、软粒子、环形波纹
和地面符文。本阶段不引入完整延迟渲染、实时全局光照或大规模底层渲染重构。

### 5.4 资产适配层

玩家、敌人和 Boss 通过模型描述配置接入，配置包含缩放、朝向、骨骼动作映射、材质覆盖
和特效挂点。资产替换不得侵入战斗状态机。

## 6. 资产采购与合规

Boss 候选必须同时满足以下条件：

- 总价不超过 500 元；
- 许可证允许商业演示和产品分发；
- 包含可用骨骼、待机、移动、受击、至少两种攻击和死亡动作；
- 面数、纹理尺寸和材质数量适合移动端；
- 可导出或转换到当前模型链路，且动作映射可验证。

实施阶段先提交候选清单、许可证证据和适配评估。购买属于外部付费操作，必须经用户单独
确认。若无候选满足门槛，则停止采购，回退到免费类人模型加程序化环体，不为购买降低
许可或技术标准。

所有第三方资产记录名称、作者、来源页、许可证、价格、下载日期、原文件 SHA-256、
派生文件及修改说明。

## 7. 性能、降级与验证边界

- Pura 70 Pro 模拟器只用于视觉、功能和流程验证，不作为真实性能结论。
- 真机目标为稳定不低于 30 FPS，争取 60 FPS；需执行完整 7 分钟帧时间、内存和温度验证。
- 性能降级顺序固定为：减少粒子、降低雾质量、关闭次要动态光、降低阴影、降低渲染比例。
- 玩家和 Boss 轮廓、三色共鸣、Boss 环体属于品牌核心，不得被降级关闭。
- 每阶段保留固定机位截图、完整录屏、流程时长和自动化状态测试证据。
- 不得用模拟器截图或模拟器 FPS 替代真机性能数据，也不得宣称未经验证的设备结果。

## 8. 实施任务

### Task 3A：资产与视觉基线

- 建立 Boss 候选清单及许可、动画、格式、面数和价格评估。
- 选定免费玩家角色和普通敌人资产。
- 完成资产适配层、暗黑遗迹色板、三源规范和基础材质模板。
- 交付包含玩家、遗迹、祭坛和远处 Boss 焦点的合格首屏。
- 本任务只验证候选与链路，实际购买需单独确认。

### Task 3B：场景与渲染重构

- 重排主路线、战斗区和祭坛，建立前中远景。
- 实现距离雾、方向光、发光材质、颜色分级和共鸣 VFX。
- 在模拟器验证视觉和功能，同时记录新增渲染成本。

### Task 3C：引导演示流程

- 实现 `DemoDirector`、阶段触发、超时兜底、跳转和异常恢复。
- 完成 5–7 分钟探索、遭遇战、三源激活和祭坛进入流程。
- 重做电影化中心轴 HUD，默认隐藏调试信息。

### Task 4：Boss 与标志性时刻

- 经单独确认后采购并接入 Boss，完成环体、碎片、核心和破环阶段。
- 完成 Boss 登场、两阶段战斗、三源反制、最终击杀和品牌收尾。

### Task 5：投资演示增强

- 增加可切换技术面板、隐藏阶段入口、故障恢复和演示讲解脚本。
- 技术展示不得常驻或破坏产品画面。

### Task 6：验收与分发

- 完成功能、流程、异常恢复和 7 分钟稳定性测试。
- 输出明确标注用途的模拟器截图与录屏，并补充真机性能证据。
- 生成签名 HAP、一键安装说明、演示操作卡和离线备份视频。

## 9. 投资 Demo 完成标准

- 启动后 20 秒内出现可用于宣传截图的首屏。
- 演示在 5–7 分钟内稳定走完，不依赖开发者临场寻找触发点。
- 玩家、普通敌人、Boss、场景和 HUD 不存在基础几何占位物。
- 投屏时目标、玩家状态和三源共鸣清晰可读，UI 不遮挡核心画面。
- Boss 静态截图中可通过悬浮环、三色核心和碎片轮廓识别。
- 至少形成遗迹首屏、Boss 登场和最终破环三个可复述画面。
- 模拟器连续完整跑通两次，任一阶段失败后可跳转恢复。
- 真机稳定不低于 30 FPS；取得真机证据前不得宣称性能验收完成。
- 第三方资产来源、许可证、价格和修改记录完整。
- 提供可安装包、完整录屏和离线备份，现场不依赖网络。

## 10. 范围控制

- 不做开放世界、多地图、复杂装备、多人功能或完整剧情。
- 不重写底层渲染架构，不追求实时全局光照或主机级画质。
- 资产预算只用于一个 Boss 核心资产，累计不超过 500 元。
- 旧计划中的自由沙盒不是投资演示验收项；如保留，只能作为隐藏或流程结束后的非阻塞入口。
- Task 1、Task 2 的已完成工程能力继续复用，但其视觉结果不构成后续质量上限。
