- 所有 UI 组件使用 @Component 装饰器导出 struct，并通过 @Prop 接收父组件下发的只读状态，内部交互状态使用 @State。
- 可点击按钮显式设置 hitTestBehavior(HitTestMode.Block)，非交互覆盖层统一设为 Transparent 或 None 以避免遮挡下层输入。
- 技能按钮采用统一的圆形渐变配色模式：可用态使用亮色线性渐变 + 外发光阴影，冷却态使用暗色渐变 + 半透明 Progress(Ring) 遮罩显示剩余秒数。
- 动画反馈通过 animateTo 配合 -1 迭代与 Alternate playMode 实现呼吸脉冲，结合 @State 布尔标志在可用/不可用态切换样式。
- 跨帧边沿检测通过 private prev* 字段保存上一帧值，在 detectCombatEvents 中比较上升沿触发 Haptics 触感反馈。
- 调试功能统一通过右上角 ☰ 按钮展开侧拉面板，面板内按钮调用 Bridge 中的 startEncounter/advanceLevel/useSupply/retryBoss/toggleDebugHud 等函数。
