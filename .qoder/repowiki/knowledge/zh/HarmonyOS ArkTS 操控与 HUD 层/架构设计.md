模块以 entry/src/main/ets/pages/GamePage.ets 为入口，通过 XComponent 嵌入 native 渲染表面，并以 setInterval(100ms) 轮询 pullSnapshot() 将 native 状态同步到 @State 字段，再作为 @Prop 下发给各 UI 组件。
- GamePage：唯一状态源，维护 Snapshot 副本与 prev* 边沿检测，负责模型/环境 GLB 资源加载并调用 nativeSetModelAssets/nativeSetEnvironmentAssets。
- Joystick.ets：仅绘制摇杆视觉反馈，使用 TouchEvent 跟踪单指移动，hitTestBehavior=Transparent 让事件穿透至下层 XComponent native 回调。
- CombatControls.ets：右下角弧形技能按钮簇，使用 ButtonType.Circle + linearGradient + Progress(Ring) 实现冷却遮罩；终结技窗口开启时 animateTo 呼吸脉冲；调试按钮收起侧拉面板。
- Hud.ets：顶部目标标签 + HP/Poise/Stamina 进度条 + 三源共鸣槽位发光圆球，debugHud 分支输出 FPS、坐标、遭遇状态等。
- 其他叠加层（HitFeedback、ActionToast、ComboCounter、Tutorial、GameStateOverlay、TargetFrame、PauseMenu）均透明命中，按 Z 序叠加。
依赖方向单向：GamePage → 各 UI 组件 → Bridge.pushAction/startEncounter/advanceLevel 等 NAPI 调用，UI 不直接访问 native 引擎。
