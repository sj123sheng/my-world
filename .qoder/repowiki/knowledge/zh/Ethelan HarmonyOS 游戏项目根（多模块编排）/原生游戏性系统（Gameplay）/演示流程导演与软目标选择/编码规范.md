- 状态/配置数据以 POD struct 形式暴露（如 `DemoPhase`、`BossCinematicState`、`SoftTargetingConfig`），并通过 const 成员函数或静态方法提供只读访问。
- 每段核心逻辑放在匿名 namespace 中声明 `constexpr` 常量（如超时阈值、π 值），避免头文件污染。
- 对外 API 采用纯函数风格：`select`、`tick` 等方法不修改对象自身状态，仅返回新值或 `std::optional` 结果，保证可测试性。
- 输入参数在进入计算前进行有限性检查（`std::isfinite`、`position.finite()`），非法输入直接返回空结果而非崩溃。
