- 状态与配置分离：通过独立的 `*Config`、`*Snapshot`、`*FrameInput` 结构体分别承载配置、运行时快照和每帧输入，控制器仅持有这些值对象。
- 枚举统一采用 `enum class ... : uint8_t` 形式，便于序列化与跨语言传递。
- 数值运算统一使用 `FixedPoint` 配合 `fp()` 宏，避免浮点精度问题。
- 状态机通过布尔标记（如 `phaseTwoTriggered_`）保证阶段单向推进且仅触发一次。
- 公开 API 遵循 start/update/applyDamage 等命名约定，所有副作用操作均先检查 `running_` 与 `defeated` 守卫。
