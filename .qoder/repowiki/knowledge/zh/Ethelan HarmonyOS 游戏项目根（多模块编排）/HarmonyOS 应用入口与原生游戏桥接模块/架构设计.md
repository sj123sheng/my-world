本模块是 HarmonyOS 应用的 entry 模块，采用三层结构：
- UI 层（src/main/ets）：EntryAbility.ets 作为应用入口，声明 module.json5 中的 EntryAbility；GamePage.ets 使用 @Entry/@Component 装饰器定义主页面，通过 XComponent 嵌入 native_game 渲染表面；Hud.ets 与 CombatControls.ets 提供叠加 UI。
- 桥接层（src/main/ets/napi/Bridge.ets）：import 'libnative_game.so' 暴露 nativeStart/nativeStop/pushInput/pullSnapshot 等函数，定义 Snapshot/InputEvent TypeScript 接口，向上屏蔽 N-API 细节。
- 原生层（src/main/cpp）：native_bridge.cpp 通过 napi_module_register 注册名为 native_game 的 N-API 模块，使用 OH_NativeXComponent 回调处理 Surface 生命周期与触摸事件，调用 ../../../../native 下的 C++ 游戏引擎（engine/core/loop、gameplay/*、platform/harmony/*）。
构建由 hvigorfile.ts 驱动 ohos-hap 任务，build-profile.json5 配置 CMakeLists.txt 路径与 arm64-v8a/x86_64 ABI 过滤，oh-package.json5 通过 file: 协议依赖本地 libnative_game.so 类型声明。
