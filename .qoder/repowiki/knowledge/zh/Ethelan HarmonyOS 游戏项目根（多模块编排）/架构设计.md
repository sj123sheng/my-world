根目录是 HarmonyOS 应用的顶层容器：AppScope/app.json5 定义 bundleName、版本与 API 级别；build-profile.json5 声明 products、buildModeSet（debug/release）、CMake 路径与 ABI 过滤（arm64-v8a/x86_64），并通过 modules 数组将 entry 模块纳入构建；hvigorfile.ts 使用 @ohos/hvigor-ohos-plugin 的 appTasks 系统任务。assets/ 存放环境布局与模型清单，config/{dev,schema} 提供运行时 JSON 配置与 schema 校验，automation/ 提供资产拉取、校验与性能采集脚本。各子模块（entry、native_engine、native_gameplay、native_platform、tests）通过 NAPI + XComponent 桥接契约协作，根层仅负责构建装配与资源/配置分发。
