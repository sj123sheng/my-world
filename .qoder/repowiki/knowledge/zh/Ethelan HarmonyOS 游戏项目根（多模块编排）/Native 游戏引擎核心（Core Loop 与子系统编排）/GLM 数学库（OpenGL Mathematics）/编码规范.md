- 每个功能模块拆分为 `.hpp` 声明文件与 `.inl` 实现文件，`.hpp` 中仅放函数/类声明并在末尾 `#include "xxx.inl"` 引入实现。
- 所有公共函数通过 `GLM_FUNC_DECL` / `GLM_FUNC_QUALIFIER` / `GLM_CONSTEXPR` / `GLM_NODISCARD` 等宏包装，由 `detail/setup.hpp` 根据编译器/平台展开为具体限定符。
- 类型模板统一携带 `<length_t L, typename T, qualifier Q = defaultp>` 三个模板参数，精度与对齐由 `qualifier` 枚举控制，并通过 `detail::storage` 模板特化选择 SIMD 或普通数组存储。
- 扩展模块（ext/gtc/gtx）遵循相同的命名与组织约定：文件名即 API 名称，配套 `.hpp` + `.inl` 成对出现，并在 `.hpp` 顶部用 Doxygen 注释标注所属 group。
- 编译器/平台/架构探测集中在 `simd/platform.h` 与 `detail/setup.hpp`，通过 `GLM_COMPILER_*`、`GLM_PLATFORM_*`、`GLM_ARCH_*` 宏集中管理，其他文件仅消费这些宏而不重复探测。
