该模块是完整的 GLM 源码副本，采用纯头文件、按功能分层的结构：
- `glm.hpp` 为核心入口，依次包含 `detail/setup.hpp`（平台/编译器/C++ 特性检测）、`fwd.hpp`（前置声明）以及 vec/mat/quaternion 类型与 core 函数（trigonometric/exponential/common/packing/geometric/matrix/vector_relational/integer）。
- `detail/` 存放底层实现：`setup.hpp` 负责编译期能力探测（C++11/14/17/20、SIMD、constexpr、aligned storage 等），`qualifier.hpp` 定义 `qualifier` 枚举（highp/mediump/lowp + aligned/packed）并暴露 `storage` 模板特化以选择 SIMD 或普通数组存储；`type_vec*.hpp` / `type_mat*.hpp` / `type_quat.hpp` 为各类型的 `.hpp` 声明与 `.inl` 实现分离。
- `ext/` 提供稳定扩展（matrix_transform/projection/clip_space、quaternion_*、scalar_*、vector_* 等），每个扩展由 `.hpp` 声明 + `.inl` 实现组成。
- `gtc/`（recommended extensions）与 `gtx/`（experimental extensions）遵循相同 .hpp/.inl 配对模式，分别对应推荐与实验性 API。
- `simd/` 目录包含平台无关的 SIMD 内联头（SSE/AVX/NEON 等），由 `setup.hpp` 中的 `GLM_ARCH_*` 宏控制启用。
- 依赖方向严格单向：`core → detail`，`ext/gtc/gtx` 仅依赖 core/detail，不反向依赖；`simd/platform.h` 被 `setup.hpp` 包含以完成平台/编译器识别。
- 所有公共 API 通过 `GLM_FUNC_DECL/GLM_FUNC_QUALIFIER` 等宏统一注入 inline/noexcept/nodiscard/CUDA 限定符，保证跨编译器一致性。
