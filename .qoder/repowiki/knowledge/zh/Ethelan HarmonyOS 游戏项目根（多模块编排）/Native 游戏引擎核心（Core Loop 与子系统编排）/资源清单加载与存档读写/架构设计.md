模块由两个独立且正交的功能单元组成：`loader.{h,cpp}` 实现 `ResourceLoader` 类，负责从 JSON manifest 文件加载 `ManifestEntry`（id、size、hash、deps）并校验资源完整性；`save.{h,cpp}` 实现 `Save` 类，通过 `.tmp` 临时文件 + `std::rename` 原子替换的方式持久化 `SaveState`（campLevel、relics、regionProgress）。两者均仅依赖 C++ 标准库 `<fstream>`，无外部依赖，接口以简单 struct + 方法形式暴露，便于被上层 engine 直接调用。当前为 MVP 实现，manifest 解析与哈希校验尚未落地，但已预留扩展点。
