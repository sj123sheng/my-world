模块以 `Loop` 结构体为唯一入口，内部组合了渲染 Surface、输入管线（InputQueue/TouchRouter/VirtualJoystick/CameraGesture）、PlayerController、SoftTargeting、CombatController、EncounterController、DemoDirector、VfxSystem、PerformanceGuard、AudioBridge 以及 FixedStep、SnapshotStore、LifecycleState 等基础设施。
- 时间推进：`FixedStep` 基于 16ms 固定步长与最大步数上限累积 elapsedMs，保证确定性更新；`tickOnce` 由独立线程以 ~60fps 调度。
- 生命周期：`LifecycleState` 通过递归互斥提供 `start/stop/synchronized` 原子包装，所有状态变更均经 `withLifecycle` 进入。
- 快照发布：每帧构建 `GameSnapshot`，经 `SnapshotStore` 互斥写入，供外部只读消费；`RendererStoppedSnapshot` 用于渲染器停止时的降级快照。
- 线程模型：主循环在 `std::thread` 中运行，输入通过带序列号的 `enqueueInput` 入队，战斗事件通过 `combatEventMutex` 保护 `CombatEventBatch` 跨帧传递。
- 依赖方向：core 向上依赖 presentation（VfxSystem、PerformanceGuard）、platform（AudioBridge）、render（Surface/Camera）、input 各子系统、gameplay 各控制器，自身不反向被这些子系统引用，形成单向汇聚。
- 平台隔离：OHOS 平台下调用 `surface_draw`/`surface_swap` 与 hilog 日志，其他平台通过宏屏蔽。
