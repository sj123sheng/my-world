- 手势类（CameraGesture、VirtualJoystick）统一采用 begin(pointerId, position) / move(pointerId, position) / end(pointerId) / clear() 四阶段生命周期，并在 begin 中记录 pointerId_ 用于后续校验。
- 配置结构体（CameraGestureConfig、VirtualJoystickConfig）在构造函数中对成员进行有限性检查并使用默认值回退，确保非法输入不会破坏状态。
- 输入事件统一通过 `InputEvent { action, pointerId, x, y, sequence }` 传递，其中 `sequence` 字段用于事件排序或去重。
- 跨边界指针类型到 `InputAction` 的映射集中在 `TryMapPointerAction` 中完成，由 `ForwardChangedPointer` 模板统一封装调用。
- 所有公共方法对浮点坐标使用 `std::isfinite` 或 `position.finite()` 进行前置校验，非法输入直接返回或忽略。
