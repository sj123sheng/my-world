模块以 `input_event.h` 中的 `InputAction` 枚举和 `InputEvent` 结构体为核心数据契约，所有子组件围绕该事件类型组织：
- 基础工具层：`pointer_input.h` 提供 `TryConvertInt32`/`TryConvertFloat`/`TryMapPointerAction` 等 inline 转换函数；`changed_pointer_forwarder.h` 通过模板 `ForwardChangedPointer` 把外部指针类型映射为 `InputAction` 并转发给 sink。
- 事件缓冲层：`input_queue.h` 的 `InputQueue` 使用 `std::queue<InputEvent>` + `std::mutex` 实现线程安全的有界队列，支持 push/pop/clear 及 dropped 计数。
- 触控路由层：`touch_router.h` 的 `TouchRouter` 根据屏幕左/右半屏分配 `TouchRole`（Movement/Camera/Ignored），维护 pointerId→role 的 `unordered_map`。
- 手势处理器：`camera_gesture.h` 的 `CameraGesture` 与 `virtual_joystick.h` 的 `VirtualJoystick` 均遵循 begin/move/end/clear 生命周期 API，累积位移并通过 `consumeDelta()`/`value()` 消费。
- 输出层：`player_intent.h` 的 `PlayerIntent` 聚合移动向量、视角增量、软锁定标志与 `ActionRequest` 列表，作为上层游戏逻辑的消费产物。
依赖方向单向：工具 → 事件 → 路由/手势 → 玩家意图，不反向依赖上层 gameplay。
