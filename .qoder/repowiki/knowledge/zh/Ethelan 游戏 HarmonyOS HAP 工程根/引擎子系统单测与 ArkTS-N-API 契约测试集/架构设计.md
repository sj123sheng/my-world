测试集采用两种并行形态且互不依赖：
- C++ 单测（`test_*.cpp`）：每个文件对应一个被测模块，通过 `#include "native/<path>/<header>.h"` 直接包含被测头，在 `main()` 中调用函数并用 `<cassert>` 断言；部分用例通过 `fork()+waitpid()` 验证断言崩溃路径。
- Node.js 契约测试（`test_bridge_contract.mjs`、`test_environment_assets.mjs`）：读取 ArkTS/N-API/C++ 源码文本，用正则匹配确保 Bridge 导出、Index.d.ts 声明、NativePullSnapshot 字段顺序与 GamePage/HUD 使用保持一致，并校验环境资产的 manifest/layout/sha256。
- 共享 fixture 工具集中在 `gltf_fixture_builder.h`，提供 `makeMinimalGlb`、`makeStaticSceneGlb`、`replaceJsonText` 等内联函数，用于在内存中构造 GLB 二进制以驱动 GLTF 解析相关测试。
依赖方向单向指向被测代码（`tests/` → `native/`），测试之间互不引用，各自独立可编译运行。
