模块以 `surface.h/.cpp` 为唯一对外入口，集中管理 EGL Display/Surface/Context、2D 单色着色器程序以及 3D 渲染管线（Camera3D、Shader3D、Mesh、StaticModel、SkinnedModel、EnvironmentController）。依赖方向单向：Surface → 各渲染组件 → GL 原生 API；游戏逻辑层仅通过 `ActorRenderState`、`Enemy3DRenderState`、`Boss3DRenderState` 等纯数据结构向渲染层写入状态，避免反向依赖。
- 资源生命周期由 `render_lifecycle.h` 中的 `PendingModelAsset` 延迟脏标记与 `SurfaceDestroyOperations` 回调编排，确保 context 丢失时只丢弃 CPU 句柄、GL 删除严格遵循 `kSurfaceGlDestroyOrder` 顺序。
- 3D 管线按 glTF 解析（`skinned_model.*`）与静态模型（`static_model.*`）分离，二者均通过 `Mesh` + `Shader3D` 提交绘制。
- 环境系统通过 `EnvironmentController` + `EnvironmentComposition` + `EnvironmentRenderPlan` 根据相机位置与性能等级动态评估批次，支持降级纹理层级。
- 平台隔离通过 `#ifdef OHOS_PLATFORM` 将 EGL/GL 调用收敛在条件编译块内，非平台侧提供空实现以便 macOS 单元测试。
