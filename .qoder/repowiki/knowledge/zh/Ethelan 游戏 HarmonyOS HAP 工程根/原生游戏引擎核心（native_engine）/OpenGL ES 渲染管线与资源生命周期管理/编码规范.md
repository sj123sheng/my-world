- 跨平台隔离统一使用 `#ifdef OHOS_PLATFORM` 包裹 GL/EGL 相关头与实现，非平台侧提供等价空实现以保证语法检查与单元测试可编译。
- GPU 资源释放采用 `destroy()` + `abandonGpuResources()` 双模式：前者在 current context 下安全删除，后者仅在 context 不可用时丢弃 CPU 跟踪句柄，禁止发出 GL 调用。
- 渲染状态通过轻量 POD 结构体（如 `ActorRenderState`、`Enemy3DRenderState`、`Boss3DRenderState`）从 gameplay 层单向传入，渲染层不修改这些结构。
- 延迟资源更新通过 `PendingModelAsset::replace/makeDirty/take` 模式实现：CPU 端标记 dirty，渲染帧消费时原子取走并清空标志。
- 几何体生成函数（`createCube/createPlane/createCylinder/createRing`）与纹理加载（`loadTexture`）在非平台侧为空操作，便于脱离 GPU 验证数据结构。
- 枚举类型使用 `enum class` 并配合 `forModel`/`ChooseAnimation`/`ResolveClip` 等 inline 辅助函数完成 kind→名称/clip 的映射，避免散落的 switch 分支。
