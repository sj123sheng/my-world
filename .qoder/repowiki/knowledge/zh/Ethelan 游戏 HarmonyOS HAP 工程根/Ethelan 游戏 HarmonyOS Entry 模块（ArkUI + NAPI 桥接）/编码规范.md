- N-API 导出函数统一通过 napi_property_descriptor 数组在 Init() 中集中注册，并以 EXTERN_C_START/END 包裹导出符号。
- ArkTS 侧通过 Bridge.ets 对每个 native_* 函数做薄封装，保持与 C++ 端参数一一对应的同步调用风格。
- C++ 侧所有 N-API 回调均使用 g_loop.withLifecycle(...) 包装，确保在引擎生命周期安全上下文中执行操作。
- 日志输出统一使用 LOGI/LOGE 宏（基于 OH_LOG_Print），并以 "Ethelan" 作为 tag 前缀。
- ArkUI 组件使用 @State 装饰器声明响应式字段，并通过 setInterval 轮询 pullSnapshot 更新 UI 状态。
- 资源加载使用 resourceManager.getRawFileContent 异步读取 rawfile/models 与 rawfile/environment 下的 GLB 文件，失败时回退到程序化生成。
