本模块采用清晰的三层结构：
- UI 层（src/main/ets/pages & ui）：EntryAbility.ets 作为 module.json5 声明的 EntryAbility 入口，onForeground/onBackground 中调用 nativeStart/nativeStop；GamePage.ets 使用 @Entry/@Component 定义主页面，通过 XComponent(type='surface', libraryname='native_game') 嵌入原生渲染表面，并以 Stack 叠加 Hud、CombatControls、Joystick、HitFeedback、ActionToast、ComboCounter、Tutorial、GameStateOverlay、TargetFrame、PauseMenu 等纯 ArkTS UI 组件。
- 桥接层（src/main/ets/napi/Bridge.ets）：import 'libnative_game.so' 暴露 nativeStart/nativeStop/pushInput/pullSnapshot 等函数，定义 Snapshot/InputEvent TypeScript 接口，向上屏蔽 N-API 细节，保持与 C++ 端参数一一对应的同步调用风格。
- 原生层（src/main/cpp/native_bridge.cpp）：通过 napi_module_register 注册名为 native_game 的 N-API 模块，在 Init() 中用 napi_property_descriptor 数组集中注册所有导出函数，并获取 OH_NativeXComponent 指针注册 OnSurfaceCreated/Changed/Destroyed/DispatchTouchEvent 回调；所有回调均通过 g_loop.withLifecycle(...) 包装确保在引擎生命周期安全上下文中执行，触摸事件经 ForwardChangedPointer 转为 InputAction 后入队。
构建由 hvigorfile.ts 驱动 ohos-hap 任务，build-profile.json5 配置 externalNativeOptions.path 指向 src/main/cpp/CMakeLists.txt，abiFilters 限定 arm64-v8a 与 x86_64；oh-package.json5 通过 file: 协议依赖本地 libnative_game.so 类型声明（src/main/cpp/types/libnative_game）。
